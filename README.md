# cricket_pisso_templates

Match Card Studio: a single-page tool for making Cricket Pisso social posts.

Open `index.html` in a browser, pick a post type, upload a photo, fill in the details and download a PNG.

## Post types

- Player figures
- Match day
- Player analysis
- Ground analysis
- Last match result
- Captain's call (bat or bowl poll)
- Toss prediction
- Wicket alert
- Injury update
- Playing XI (with captain and wicket-keeper menus)
- Toss result

## Features

- Square (1080 × 1080), portrait (1080 × 1350) and story (1080 × 1920) sizes
- Drag to position the photo, both logos and the page name
- Remove the plain background from a logo
- Team colour picker
- Text, logos and positions are remembered in the browser
